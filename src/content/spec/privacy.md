# 隐私政策

最后更新日期：2024 年 5 月 20 日
生效日期：2024 年 5 月 20 日（建站当日）

## 1. 信息收集

本网站仅通过服务器日志自动收集访客的 **IP 地址**。该信息仅用于以下目的：
- 提供天气定位服务（通过 IP 获取大致地理位置）
- 网站访问统计分析
- 安全防护和故障排查

**我们不会**：
- 存储任何个人敏感信息（如姓名、电话、邮箱等）
- 追踪用户浏览行为
- 将 IP 地址与个人身份关联

## 2. 第三方服务

本网站使用以下第三方 API 服务，其隐私政策适用各自的规定：

### 2.1 高德地图 API
- **用途**：提供天气数据查询和地理位置定位服务
- **收集信息**：IP 地址（用于定位）
- **隐私政策**：https://lbs.amap.com/home/privacy/

### 2.2 MetingAPI
- **用途**：提供音乐播放功能
- **收集信息**：无个人信息收集
- **说明**：仅用于加载公开的音乐资源

## 3. 数据安全

- 所有数据传输均采用 HTTPS 加密
- 我们不向任何第三方出售、出租或分享用户数据
- 服务器日志定期清理，不长期存储 IP 地址

## 4. 用户权利

您有权：
- 了解我们收集的关于您的数据
- 要求删除您的数据（通过清除浏览器缓存实现）
- 选择不使用某些功能（如关闭天气显示）

## 5. 儿童隐私

本网站不针对 13 岁以下儿童，也不会故意收集儿童的个人信息。

## 6. 政策更新

我们可能会不时更新本隐私政策。更新后的政策将在此页面发布，并标注最新更新日期。

## 7. 联系我们

如您对本隐私政策有任何疑问，请通过网站联系方式与我们联系。
