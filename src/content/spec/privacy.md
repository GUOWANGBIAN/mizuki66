## 1. 信息收集

### 1.1 服务器日志

当您访问本网站时，我们的服务器会自动记录以下信息：
- **IP 地址**：用于安全防护、访问统计和地理位置定位
- **访问时间**：记录请求发生的时间戳
- **请求方法和路径**：您访问的页面地址
- **User-Agent**：浏览器和操作系统信息
- **Referer**：来源页面（如有）

这些日志信息仅用于以下目的：
- 网站访问统计分析
- 安全防护（如防止恶意攻击、滥用行为）
- 故障排查和性能优化
- 提供天气定位服务（通过 IP 获取大致地理位置）

### 1.2 浏览器本地存储

本网站可能使用浏览器的 localStorage 存储以下信息：
- 主题偏好（深色/浅色模式）
- 界面设置（如布局模式、壁纸选择）
- 音乐播放器状态

这些数据仅保存在您的设备上，不会上传到服务器。

**我们不会**：
- 存储任何个人敏感信息（如姓名、电话、邮箱等）
- 追踪用户在站外的浏览行为
- 将 IP 地址与个人身份关联
- 使用 Cookie 进行用户追踪或广告投放

## 2. 第三方服务

本网站使用以下第三方服务，其数据处理受各自隐私政策约束：

### 2.1 高德地图 API
- **用途**：提供天气数据查询和地理位置定位服务
- **数据传输**：您的 IP 地址会发送至高德服务器用于定位
- **隐私政策**：https://lbs.amap.com/home/privacy/

### 2.2 MetingAPI（音乐播放）
- **用途**：提供音乐播放功能
- **数据传输**：播放请求会发送至第三方音乐 API 服务器
- **说明**：仅用于加载公开的音乐资源，不涉及个人信息

### 2.3 字体服务
- **用途**：加载网站使用的字体文件
- **说明**：字体文件托管在本站服务器，不涉及第三方数据传输

## 3. IP 地址处理

IP 地址是本网站收集的主要信息之一，我们对其处理方式如下：

- **存储周期**：服务器访问日志保留 30 天，到期后自动清理
- **使用限制**：仅用于上述声明的目的，不会用于其他用途
- **访问控制**：仅管理员可访问日志数据
- **匿名化**：在统计分析时，我们会对 IP 地址进行匿名化处理

## 4. 数据安全

- 所有数据传输均采用 HTTPS 加密
- 我们不向任何第三方出售、出租或分享用户数据
- 服务器日志定期清理，不长期存储
- 采取合理的安全措施保护服务器和数据

## 5. 用户权利

您有权：
- 了解我们收集的关于您的数据
- 要求查看或删除您的相关数据
- 选择不使用某些功能（如关闭天气显示、禁用音乐播放）
- 通过浏览器设置阻止或清除本地存储

如需行使上述权利，请通过网站联系方式与我们联系。

## 6. 儿童隐私

本网站不针对 13 岁以下儿童，也不会故意收集儿童的个人信息。

## 7. 政策更新

我们可能会不时更新本隐私政策。更新后的政策将在此页面发布，并标注最新更新日期。建议您定期查看本页面以了解最新信息。

如您对本隐私政策有任何疑问，请通过网站关于页面的联系方式与我们联系。
